\# CIS480 Semiconductor Market Analysis



Historical performance and risk analysis of five semiconductor

companies: AMD, AVGO, INTC, NVDA, and TSM.



Benchmark: SPY

Analysis period: January 2021 - December 2025



\## Project Overview



This academic capstone project uses Python, Jupyter Notebook,

and Power BI to examine historical market performance.



Key metrics:

\- Cumulative Return

\- Annualized Volatility

\- Maximum Drawdown



\## Data Availability



Historical market data was retrieved using yfinance.



Original and processed market-price datasets are not

distributed in this repository.



Derived KPI datasets and the Power BI semantic model are

also excluded pending redistribution-rights review.



\## Project Status



Public-release preparation in progress.



This analysis is educational, describes historical

performance, and is not investment advice.
